# Eyad Eldokany — AI Engineering Portfolio / v2

إعادة تصميم كاملة باتجاه **AI Systems / Neural Interface**. هذه النسخة تستبدل التصميم التحريري السابق: خلفية كحلية داكنة، تدرجات أزرق وسماوي، خطوط تقنية، وخريطة أنظمة تفاعلية بدل التركيز على الصورة الشخصية والزخارف العامة.

## التشغيل

يتطلب Node.js 20.19+ وnpm.

```bash
npm install
npm run dev
```

للإنتاج:

```bash
npm run build
npm run preview
```

## النشر على Vercel

- Framework: **Vite**
- Build: `npm run build`
- Output: `dist`
- لا يحتاج الموقع إلى مفاتيح API أو متغيرات بيئة.

`vercel.json` مرفق. لم يتم تعديل الموقع الأصلي أو نشر النسخة على حسابك؛ النشر يحتاج حساب الاستضافة الخاص بك.

## الفكرة والتنظيم

1. **Identity / Interactive system map** — تعريف مباشر بالاسم ومجال AI Engineering. اختر Agentic AI أو Computer Vision أو Production ML، ثم اضغط عقد الخريطة لقراءة معنى كل مرحلة. يمكن إيقاف الحركة.
2. **Background / trajectory** — الصورة بألوانها الطبيعية والنبذة بجوار خط زمني منظم للخبرة والتعليم.
3. **Selected systems** — مشروع HealthBridge رئيسي مع تبديل بين Architecture وProduct، ثم CodeNova وEdge AI وTraffic Sign Detection. فلاتر ومؤشر كامل لعشرة مشاريع.
4. **Engineering capabilities** — مستكشف لأربعة تخصصات مع مخطط عمل وتقنيات ومشاريع مرتبطة بكل تخصص. قائمة التقنيات الكاملة قابلة للفتح.
5. **Credentials** — أربعة اختيارات مختصرة، مع الوصول إلى الشهادات الإحدى عشرة وصورها وروابط التحقق.
6. **Contact** — البريد والنسخ وروابط GitHub وLinkedIn والعمل الحر.

### التفاعلات

- `Ctrl+K` / `⌘K`: البحث في الأقسام والمشاريع والتقنيات.
- ابحث مثلًا عن `RAG` أو `YOLO` أو `FastAPI`.
- أسهم لوحة المفاتيح وEnter داخل البحث، وEscape للإغلاق.
- مستكشف HealthBridge: Overview / Architecture / Gallery / Demos.
- الصور والفيديوهات الأصلية للمشروع، وروابط المستودعات والتطبيق الفعلي لـCodeNova.
- احترام تفضيل تقليل الحركة، ودعم لوحة المفاتيح والتصميم المتجاوب.

## تعديل المحتوى والتصميم

| الملف | الغرض |
|---|---|
| `src/content.json` | المحتوى القابل للتعديل: البيانات الشخصية، المشاريع، الخبرات، التعليم، الشهادات، المهارات، القدرات والخريطة |
| `src/portfolio.js` | تجهيز بيانات JSON للعرض، إخفاء العناصر وحساب الأعداد والفئات تلقائيًا |
| `src/App.jsx` | الأقسام، البحث، التبويبات، النوافذ، والفلاتر |
| `src/NeuralScene.jsx` | خريطة الذكاء التفاعلية |
| `src/ProjectArt.jsx` | مخططات الأنظمة، Architecture، والرسوم التوضيحية للبطاقات |
| `src/styles.css` | الهوية البصرية الجديدة وقواعد الاستجابة |
| `public/images/` | الصور والأصول المحلية |
| `public/Eyad-Eldokany-Resume.pdf` | سيرة ذاتية من بيانات البورتفوليو |
| `scripts/create-resume.py` | إعادة إنشاء PDF (يتطلب `pip install reportlab`) |
| `scripts/export-standalone.py` | تصدير HTML مستقل بعد البناء |

**دليل التعديل الكامل بالعربي:** [نسخة سهلة القراءة في المتصفح](CONTENT-EDITING-GUIDE.ar.html) · [نسخة Markdown قابلة للتحرير](CONTENT-EDITING-GUIDE.ar.md). يشرح خانات JSON، إضافة المشاريع والخبرات والشهادات، الصور، الإخفاء والترتيب، إعادة البناء والنشر، والخانات القديمة التي لا تتحكم في الواجهة.

المحتوى التقني الذي كان في `portfolio.js` أصبح داخل `content.json` لتقدر تعدّله من ملف واحد، مع الحفاظ على نفس التصميم والنصوص المعروضة.

## HTML مستقل

```bash
npm run build
python3 scripts/export-standalone.py ../Eyad-Eldokany-AI-Portfolio.html
```

يشمل الملف المستقل JavaScript وCSS والخطوط والصور والسيرة الذاتية، ويمكن فتحه دون خادم. الإنترنت مطلوب فقط عند فتح المواقع الخارجية أو تشغيل YouTube. بعض عوارض الملفات المضمنة قد تقيّد فتح روابط خارجية؛ تنزيل HTML وفتحه في المتصفح يتجنب ذلك.

## الاختبار

```bash
npx playwright install --with-deps chromium
npm run dev
# في نافذة أخرى
npm run test:ui
npm run test:content
```

يدعم `TEST_URL` لتغيير عنوان الاختبار. الاختبارات تغطي:

- الخريطة وأوضاعها وتفاصيل العقد وإيقاف الحركة.
- المشاريع العشرة والفلاتر ومعرض المنتج ومخطط Architecture.
- التبويبات والقدرات والتقنيات والخبرة والتعليم والشهادات.
- البحث بلوحة المفاتيح والنسخ والقائمة المحمولة وملف PDF.
- عشرة أحجام شاشة من 320 إلى 1920 بكسل.
- فحوص axe-core آلية على الكمبيوتر والموبايل. ليست شهادة امتثال شاملة لكل متطلبات الوصول.

## ملاحظات مهمة

- هذه واجهة بورتفوليو مستقلة، وليست لوحة مراقبة أو API أو نموذج AI يعمل في الخلفية.
- الخريطة والرسوم التوضيحية تصوّر أفكار العمل والتقنيات؛ لا تعرض نتائج أو نسب أداء أو اتصالات حية مزعومة.
- أصل الخريطة البصري `neural-core.webp` رسم تجريدي مولّد بالذكاء الاصطناعي. التفاعل والشرح والروابط منفذة برمجيًا.
- صور HealthBridge والشهادات والصورة الشخصية من البورتفوليو الأصلي.
- بيانات الإنجازات مأخوذة من المصدر، وليست تحققًا مستقلاً منها.
- ملف PDF صيغ من بيانات البورتفوليو، وليس نسخة من سيرة ذاتية أصلية مرفوعة. راجعه قبل التقديم.
- زر التواصل يفتح تطبيق البريد، ولا يدّعي إرسال رسائل من خدمة خلفية.
- لم تُنسخ إعدادات Firebase أو تسجيل الدخول أو لوحة التحكم الأصلية.
